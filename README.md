## ⚡ Deployment Instructions

### Option 1: Deploy to Vercel (Recommended)
This repository includes a `vercel.json` configuration. Simply run:
```bash
npx vercel
```
Or import this repository on [vercel.com](https://vercel.com) for instantaneous global CDN deployment.

### Option 2: Deploy to GitHub Pages
1. Push this repository to GitHub under your account (`amazoe-solutions`).
2. Go to **Settings → Pages**.
3. Under **Branch**, select `main` / `root` and click **Save**.
4. Your site will be live at `https://<your-username>.github.io/amazoe-solutions`.
